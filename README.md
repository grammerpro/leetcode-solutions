            ## 🔍 About

            This repository is my personal archive of solved LeetCode problems. Every solution is written with clarity and optimal algorithmic complexity in mind. Rather than just passing tests, each file aims to be readable, well-structured, and educational for anyone learning DSA.

            > Solutions are organized by difficulty and topic. The repo is updated regularly after each problem set.

            > ## 🚀 How to Use
            >
            > ### Prerequisites
            >
            > - **Python** 3.8+
            >
            > - ### Run a solution
            >
            > - ```bash
            >   git clone https://github.com/grammerpro/leetcode-solutions.git
            >   cd leetcode-solutions
            >
            >   # Run any solution directly
            >   python Easy/invert_binary_tree.py
            >   python Medium/coin_change.py
            >   ```
            >
            > Each file is self-contained and includes the problem description, constraints, and at least one example in the docstring.
